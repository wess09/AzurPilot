# 证券总行动力采集修复

## 原因与修复

`OIL_ITEM` 和 `ACTION_POINT_ITEMS` 共用数量 OCR。普通行动力面板读取先识别一格石油，再识别三格行动力箱；第二次识别覆盖 `last_batch_validity`。原流程在两次识别之后才合并校验结果，实际得到两组三格结果，导致完整库存始终不能通过四格校验。当前行动力和运行日志仍会更新，但本次总行动力不会写入认证历史，证券同步因此没有新样本。

每月开荒等任务使用普通读取路径。侵蚀一、短猫和智能调度使用的合批路径不受这个覆盖问题影响，因此可能出现任务切换后证券报价停更的现象。

修复在石油识别后立即保留该批校验结果，再与箱子结果合并。总行动力继续要求当前行动力与完整库存均通过验证；不使用旧箱子库存、当前行动力或日志补造总量。开箱开关只影响游戏内使用策略，统计总量仍包含全部行动力箱。

另一个遗漏是零库存箱格：游戏面板可能不显示数量文字，通用 OCR 的空文本会返回数值 0，但校验结果仍为无效。只要三种箱子中有一格为空，总行动力就会被跳过，普通读取与合批读取都受影响。通用 OCR 仍须区分空文本与明确识别的数字 0，不能在所有场景中放宽。

当前增加了仅用于行动力观测的空箱判定：四格数量及校验结果完整、石油已有效识别且大于 100、同帧的使用和取消按钮均出现时，才检查未识别且数值为 0 的箱格；其数量区经原预处理后必须完全没有文字像素。有未识别文字、微弱字形、加载未完成或石油无效时仍不记录总量，当前行动力也必须另行通过校验。该判定只改变总量写入统计和认证历史的资格，不改变库存数值、游戏内库存缓存校验、购买与开箱策略、任务调度。
