# 实例账号管理

智能港区设置（`Alas` 任务页）提供账号管理面板。当前只支持国服 B 站客户端 `com.bilibili.azurlane`，必须配置明确的模拟器序列号，并提供 root ADB 或 `su` 权限。默认不访问游戏账号文件，不采集账号，也不恢复账号。

## 使用流程

1. 设置独立于 WebUI 密码的实例密码，至少 16 个字符且含至少 8 种不同字符，建议使用随机密码或长口令。
2. 停止使用同一模拟器的所有实例。在游戏中登录所需账号，输入实例密码，点击「备份当前游戏账号」。备份会停止游戏。
3. 如需保存其他账号，手动登录后再次备份。每个快照保存当时的登录状态。
4. 输入密码并查看账号，再输入密码点击所需快照的「切换并启动游戏」。切换前停止游戏，校验并恢复登录文件，然后启动游戏。登录凭据过期、风控验证或服务器要求重新登录时仍需人工处理。
5. 可启用「每次启动游戏前恢复选定账号」。未解锁时启动失败，不会绕过保险库使用设备上原有账号。不开启该开关时没有自动读取和写入。
6. 无 TPM 的 Windows/Linux 主机可选择「绑定本机密钥自动解锁」；有可用 TPM 的 Windows 主机仍可选择 TPM 方式。无可用 TPM 时才显示本机密钥选项，并在设置行和密码弹窗标注「安全性低于 TPM」；已有本机密钥绑定始终保留解除入口。能力探测结果在服务进程内缓存，修改 TPM 配置后需重启服务。两种方式互斥，切换前需验证实例密码解除旧绑定。绑定后服务重启可自动解锁；还需开启启动恢复开关并选定账号才会写入游戏。未绑定时，WebUI 服务重启后需输入实例密码。

页面不常驻密码输入框。点击备份、查看、切换、删除、启动解锁、修改密码、本机密钥/TPM 绑定或自动恢复开关后弹出操作密码框，验证本次密码后才执行；取消、关闭、切换页面或进入后台会清空输入，取消开关操作保持原状态。清除内存解锁和隐藏账号信息可直接操作。账号身份只有在点击查看并在弹窗验证密码之后才返回浏览器，60 秒后、切换页面或页面进入后台时隐藏。前端从不保存实例密码到浏览器存储，接口不返回登录 token、数据库内容或账号原密码。修改密码需要当前密码；删除当前选定快照会关闭启动恢复。删除实例也删除其账号保险库。

## 数据范围与设备一致性

每次备份和恢复在游戏停止后重新检测应用私有目录，优先使用 `/data/user/0/com.bilibili.azurlane/`，缺少可读的 `databases/users.db` 时尝试兼容路径 `/data/data/com.bilibili.azurlane/`。整次事务只使用一个检测成功的目录，数据库、偏好、边文件和回滚暂存均位于该目录；不会混用两个目录中的文件，也不会创建不存在的应用目录。快照只存相对文件名，因此旧快照无需迁移即可在两种路径下恢复。

已在授权模拟器检查数据库结构：`databases/users.db` 的 `users` 表包含登录凭据；Heart、track、Bugly 和 neuron 数据库是统计或错误上报数据，不作为账号快照。

快照必须包含 `users.db`；其余文件可选，设备存在且可读时采集 SDK 的 `shared_prefs/com.bilibili.azurlane_preferences.xml`，以及 Unity 的 `shared_prefs/com.bilibili.azurlane.v2.playerprefs.xml` 中 `user.*`、`server.id*`、`loginedServer_*` 登录字段。缺少任意偏好文件不阻止备份，只有 `users.db` 的快照也可以恢复；恢复仅操作快照包含的文件，不清理未包含的偏好。仅恢复数据库能否直接登录取决于客户端版本及当前 SDK 状态，未在另一台电脑上完成登录实测。Unity 其他游戏偏好在恢复时保留。快照可能包含 SDK 历史登录账号；列表展示的是快照内身份，切换单位是整份登录状态快照。

采集前强制停止游戏并正向确认进程退出。遇到非空 SQLite WAL 或回滚日志拒绝采集，避免保存不完整事务。兼容直接 root 的 adbd 及 `su -c`、`su 0 sh -c`、`su root sh -c`；只通过无副作用的 UID 查询协商 root 形式，不对写入失败自动重试。MuMu Android 12 的 `su` 长命令参数可返回 255，因此无数据脚本通过 Base64 标准输入传给 shell，不将恢复和回滚长脚本放入 `su` 参数。ADB 超时、传输校验失败、非空账号事务日志分别报告，错误不包含底层输出或账号内容。传输使用有超时的 ADB 标准输入/输出，不在主机创建明文数据库或 XML 文件。恢复在应用私有目录暂存和备份，保持应用 UID/GID、660 权限及 SELinux 上下文；恢复失败整组回滚。设备断连或回滚失败时，私有 `.azurpilot-account-*` 恢复目录可能被保留，需先人工确认原文件恢复状态再重试。游戏自动化 worker 与账号 API 共享父进程生命周期锁；启用账号管理时禁止同一模拟器同时运行多个受管理实例。独立启动的外部脚本不受 WebUI 进程登记管理，不应同时操作该模拟器。

## 加密与 TPM 的保护边界

`config/<实例名>/config.db` 是保存加密负载的 SQLite 容器，不是原样复制的游戏数据库。账号身份、快照名称和游戏文件一起使用 AES-256-GCM 加密并认证。每个保险库生成 2048 位（256 字节）随机盐并存入容器；使用 scrypt（N=2^17、r=8、p=1，约 128 MiB 内存成本）从实例密码派生 256 位密钥。每次保存生成新的 96 位随机 nonce；实例名、启用标记和自动解锁封装数据作为认证附加数据。密码不存储，密码校验通过密文认证完成，验证失败短暂限速。SQLite 旧页和回滚日志只包含密文。

AES 没有 2048 位密钥模式。2048 位在本功能中分别指随机盐长度和 TPM RSA 密钥长度。

TPM 绑定使用 Windows `Microsoft Platform Crypto Provider` 创建当前用户的不可导出 RSA-2048 私钥，以 RSA-OAEP-SHA256 封装保险库 AES 密钥。私钥保存在 Windows/TPM 的密钥存储中，项目只保存封装后的密钥。每次读取状态、密码验证、启动或恢复都重新校验 TPM，内存已解锁和自动恢复关闭时也不能绕过。提供者或硬件不可用、TPM 解封失败、密文认证失败或本机身份不匹配时立即销毁保险库，不重试 TPM、不回退到密码或软件密钥。首次绑定前的独立能力检测未通过时拒绝操作并保留保险库；能力检测通过后，首次绑定的回环验证失败同样销毁当前保险库。修改密码会重新封装新密钥；取消绑定移除保险库里的自动解锁封装，不销毁 Windows 中的私钥，以免影响已有加密备份。新绑定保存 Windows MachineGuid 的哈希用于检查主机变化，封装整体参与密文认证；旧版绑定仍通过实际 TPM 解封验证设备。TPM 密钥名称绑定项目绝对路径和实例名，迁移路径、Windows 用户、设备或清除 TPM 会使绑定失效并触发销毁；临时故障也会触发，正确密码不能恢复已销毁的数据。

未绑定自动解锁时通过密码解锁；TPM 绑定后的人工密码验证也必须通过 TPM 校验。软件本机绑定的人工操作仍需实例密码，密钥缺失时可凭密码解除绑定；检测到身份变化后无法恢复。复制全部项目文件到其他设备无法使用原 TPM 解锁，但仍可对密码做离线猜测，因此不能承诺弱密码无法破解。TPM 也不能阻止已控制原主机、拥有当前 Windows 用户权限的程序调用自动解锁或读取进程内存。浏览器密码门禁不是 TPM 对软件调用者身份的认证。远程账号操作要求 HTTPS/WSS；ADB、本机运行环境及已经恢复明文的 Android 游戏私有目录均须可信。

实现入口：`module/runtime/account_vault.py`、`account_tpm.py`、`account_local.py`、`account_device.py`，API 为 `accounts.status` / `accounts.manage`。所有敏感字段绕开普通配置和日志；异常只返回预定义消息，不打印底层 ADB 输出、密文解密内容或密码。

## TPM 失败即销毁

失败时先清零当前进程缓存密钥，再持久化不含盐、密钥或账号内容的 `config/<实例名>/account.destroyed` 标记。随后覆写、同步落盘、截断并删除 `config.db` 及 `-journal`、`-wal`、`-shm` 边文件，盐随数据库一起销毁。其他进程发现标记后也清除自己的缓存；所有启动和恢复入口拒绝继续操作，不能因为数据库不存在而退回设备上的原账号。只有用户明确重新设置实例密码，且确认实例停止后，才能清除标记并建立空保险库；旧快照无法恢复。

文件被占用或磁盘权限错误时仍尝试清理其余文件，返回 `VAULT_DESTROY_FAILED` 如实报告未能完成销毁，保留禁用标记并继续禁止使用；下次访问再次尝试清理。当前游戏私有目录、既有外部备份和已被复制走的文件不在这次本地保险库销毁范围内。文件覆写不等同于 SSD 全介质物理擦除，不能保证清除闪存磨损均衡或快照保留的历史块，参见 [NIST SP 800-88 Rev. 2](https://csrc.nist.gov/pubs/sp/800/88/r2/final)。


## 不依赖 TPM 的本机自动解锁

`bind_local` / `unbind_local` 必须验证本次实例密码，且实例停止后才能执行。首次绑定使用独立随机 256 位本机密钥，以 AES-256-GCM 封装保险库密钥；绑定前执行回环校验。项目数据库只存封装密文、随机 key id 和身份哈希，不存本机随机密钥。绑定失败保留原保险库，自动恢复仍默认关闭。修改实例密码时用同一本机密钥重新封装新保险库密钥，不在用户目录留下多个旧密钥。

- Windows：密钥位于 `%USERPROFILE%/AppData/Local/AzurPilot/account-keys/`，使用当前用户的 DPAPI 加密保存；目录 DACL 仅授予当前用户完整权限并禁止继承。DPAPI 不需要 TPM，采用用户范围，不使用允许同机其他用户解密的 `CRYPTPROTECT_LOCAL_MACHINE`。参见 [微软 DPAPI 文档](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。
- Linux：密钥位于 `~/.local/share/azurpilot/account-keys/`，目录 `0700`、文件 `0600`，每次自动解锁验证当前 UID、权限及普通文件类型。此方案的文件含随机明文密钥，依赖用户权限与系统安全；可配合磁盘加密，但程序不会把公开标识伪装成密钥密码。

路径拒绝符号链接、junction、越界 key id 和项目内存储位置。每个实例及项目路径有独立上下文，密钥文件与封装均绑定该上下文。解除绑定和删除实例会清理对应项目外密钥；销毁保险库也尝试清理对应密钥。读取或写入不输出密钥、密码或底层异常内容。

Windows 用 MachineGuid 与当前用户 SID，Linux 用 `/etc/machine-id`（备用 `/var/lib/dbus/machine-id`）与当前 UID 检测系统/用户变化；只保存哈希并参与密文认证。这些标识可被复制或修改，不能作为秘密密钥，也不构成硬件证明。重装系统通常改变标识，克隆或备份恢复可能保留它；不得宣称必然检测到所有设备变化。

检测到主机/用户身份不匹配时，沿用销毁策略清零缓存并销毁盐、数据库与边文件。密钥丢失、权限不安全、DPAPI 无法解密或项目路径迁移则阻止自动启动，即使存在缓存也不能绕过；正确实例密码仍可解除软件绑定后重建，不能自动降级到未管理的游戏账号。身份读取临时失败只阻止使用，不据此认定已更换设备。首次绑定失败也不销毁密码保险库。

仅复制项目文件不能使用本机自动解锁，但密码派生路径仍可离线猜测；Linux 的密钥文件与数据库一起泄露可被解密，控制原用户、管理员/root 或完整系统克隆也超出软件方案的保护范围。隐藏文件名、机器标识和复制限制不替代密码学保密。Windows 用户 DPAPI 也不是不可导出的硬件密钥，不承诺系统完全失陷后安全。

OpenSSH 的 ML-DSA44 + Ed25519 是混合签名方案，不能直接用来加密此保险库；本实现使用 AES-256-GCM，不冒称实现了混合后量子公钥加密。参见 [OpenSSH 算法说明](https://www.openssh.org/specs.html) 与 [NIST ML-DSA 标准](https://csrc.nist.gov/pubs/fips/204/final)。
